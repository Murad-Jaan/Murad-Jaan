# Install your animated GitHub profile

1. Open your GitHub profile repository. It must be named exactly your GitHub username.
2. Replace its `README.md` with the README in this package.
3. Upload the entire `assets` folder, preserving filenames.
4. Commit the changes and refresh your profile.

Expected structure:

```text
your-username/
├── README.md
└── assets/
    ├── red-team-banner.gif
    ├── recon-radar.gif
    └── terminal-session.gif
```

If your GitHub username is not `Murad-Jaan`, replace that username in the stats image URLs in README.md.

GitHub README does not execute custom JavaScript or CSS. Motion here is delivered as animated GIF assets, which GitHub can display. Stats/activity images are external services and may sometimes be unavailable.
